# Práctica Google Apps Script

## Descripción
Proyecto realizado en Google Apps Script para búsqueda de negocios.

## Funciones

### ls(arg)
Busca negocios por:
- teléfono
- web
- correo
- todos los anteriores

### lsV(tipoVialidad, nombreVialidad)
Busca negocios por vialidad.

### lsGPS(latitud, longitud)
Busca los 5 negocios más cercanos usando coordenadas GPS.

## Tecnologías usadas
- Google Apps Script
- JavaScript
- Google Sheets
